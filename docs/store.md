# Handouts

Some clues deserve a reveal. Attach an image or web page to a token, check it privately, then put it in front of your players when the moment arrives. They see it full screen; you keep your map and a small preview. Hit **Dismiss** when the moment is over.

Each token can hold up to three handouts. A letter, a portrait, a map detail, a suspiciously convenient diagram -- whatever you need to show on cue.

## Set up a handout

1. Select a token and open **Handouts** from its context menu. You can also manage tokens with handouts from the extension's settings panel.
2. Choose **Asset** to pick an image already in your Owlbear Rodeo library, or **Link** to enter a web URL.
3. Use the eye icon to open the handout privately. Use the present icon to show it to connected players.

While a handout is up, your players see it full screen. Your preview has a **Dismiss** button, and you can move the preview to any corner of the screen or change its height in settings. Presenting a different handout replaces the one currently showing. Players who join mid-presentation see the current handout automatically.

## About assets and links

**Asset** selects an image asset you've already uploaded to Owlbear Rodeo. (It does not upload a new file). 

**Link** takes a URL ending in common image extension (such as `.png`, `.jpg`, `.gif`, and `.webp`) a full-screen image. Other non-image URLs open as web pages. Note: Some sites block pages from being embedded; if a page comes up blank, try a direct image URL or a page that allows embedding. Also: Handouts supports hosted images and pages only; local files and `file://` links cannot be shared with players through Handouts.
