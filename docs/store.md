# Handouts

An extension to add handouts -- including Owlbear Rodeo assets or links to images or web pages -- to any scene. Allows the GM to preview a handout privately, or share with their players as a full-screen overlay covering the map.

A letter, a portrait, a picture of a monster, a city map, a suspiciously convenient diagram -- give each handout a name so you can find it when you need it. The extension supports searching and drag-and-drop sorting of handouts.

## Set up a handout

1. Open **Handouts** from the extension action and choose **+ Add Handout**.
2. Click the name to rename it. Choose **Asset** to pick an image already in your Owlbear Rodeo library, or **Link** to enter a web URL.
3. Search by name when the list grows. Use the eye icon to view a handout privately or the present icon to show it to connected players.
4. Sort the list by dragging and dropping handouts.

Each scene has its own handout list. While a handout is up, your players see it full screen. Your GM preview has a **Dismiss** button, and you can move it to any corner of the screen or change its height in settings. Presenting a different handout replaces the one currently showing.

Players who join mid-presentation see the current handout automatically, allowing GMs to set up intro or start screens for their sessions.

## About assets and links

**Asset** selects an image already uploaded as an asset to Owlbear Rodeo. It does not upload a new file.

**Link** displays URLs ending in common image extensions (such as `.png`, `.jpg`, `.gif`, and `.webp`) as full-screen images. Other URLs open as full-screen web pages in an (iframe). Note: Some sites block embedded pages; if a link to a page appears blank or broken, try using a link to a direct image URL file, or a site that allows embedding. Local files and `file://` links cannot be shared through Handouts.
