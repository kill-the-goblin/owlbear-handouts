# Handouts

Some clues deserve a reveal. Keep your handouts together for the scene, check one privately, then put it in front of your players when the moment arrives. They see it full screen; you keep your map and a small preview. Hit **Dismiss** when the moment is over.

A letter, a portrait, a map detail, a suspiciously convenient diagram -- give each handout a name so you can find it when you need it.

## Set up a handout

1. Open **Handouts** from the extension action and choose **+ Add Handout**.
2. Click the name to rename it. Choose **Asset** to pick an image already in your Owlbear Rodeo library, or **Link** to enter a web URL.
3. Search by name when the list grows. Use the eye icon to view a handout privately or the present icon to show it to connected players.

Each scene has its own handout list. While a handout is up, your players see it full screen. Your preview has a **Dismiss** button, and you can move it to any corner of the screen or change its height in settings. Presenting a different handout replaces the one currently showing. Players who join mid-presentation see the current handout automatically.

## About assets and links

**Asset** selects an image already uploaded to Owlbear Rodeo. It does not upload a new file.

**Link** displays URLs ending in common image extensions (such as `.png`, `.jpg`, `.gif`, and `.webp`) as images. Other URLs open as web pages. Some sites block embedded pages; if one appears blank, try a direct image URL or a site that allows embedding. Local files and `file://` links cannot be shared through Handouts.
